Project Summary

This project tackles a supervised regression problem: given 25 car specifications, predict the market price in USD. The data comes from the UCI Machine Learning Repository's Automobile Dataset (199 records).

The full pipeline covers exploratory data analysis, preprocessing (median/mode imputation, StandardScaler, OneHotEncoder), feature engineering via Extra Trees importance ranking, comparison of 10 regression algorithms with 5-fold cross-validation, and final hyperparameter tuning of the best-performing Random Forest via GridSearchCV.

  • Dataset: UCI Automobile Dataset (carprice.csv)
  • Best model: Tuned Random Forest — R² ≈ 0.953
  • Top predictors: engine-size, curb-weight, horsepower, highway-mpg
  • Frontend: this dashboard + ipywidgets in-notebook UI
